# media_lesson

현재 기준 소스는 `index.html`입니다. MediaPipe 검지 추적과 핀치로 모래를 그리고, 움직임에 따라 Web Audio 모래 마찰음을 생성합니다.

## 실행과 조작

Chrome에서 HTML을 열거나 HTTPS 배포 주소로 접속합니다. 손·얼굴 인식 모델을 불러올 때 인터넷이 필요합니다.

- 웹캠 켜기 → 손 전체를 보여주기 → 엄지·검지를 붙여 그리기. 떼면 멈춥니다.
- 그리기 메뉴에서 검지 끝으로 바로 그리기도 선택할 수 있습니다.
- 마우스 테스트에서는 누른 채 드래그합니다. 터치 입력도 같은 포인터 경로를 사용합니다.
- 모래 고르기로 자국을 초기화합니다.
- 효과음은 먼저 화면이나 버튼을 클릭해야 활성화되며, 멈추면 사라집니다.

웹캠·손 스켈레톤·기존 얼굴 미리보기를 유지합니다. 영상은 브라우저 안에서 처리하며 업로드·녹화하지 않습니다.

## 검증

JavaScript 문법 검사, Headless Chrome의 마우스 그리기·자국 유지·초기화, Web Audio 초기화 및 실행 상태를 확인했습니다. 실제 모바일 기기의 웹캠 추적·성능·스피커 청취는 현장 확인이 필요합니다.

## 작업 원칙

요청한 현재 단계만 수정하고 변경 사항과 테스트 결과를 보고합니다. 요청하지 않은 기능은 추가하지 않습니다.
